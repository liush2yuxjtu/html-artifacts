The UX story is now simple.

This prototype turns the audit into one coherent interaction model instead of adding more decorative motion.

01 · P0

Prompt → visible work

A visitor can trigger the core value immediately and watch the AI move through understandable edit states.

02 · P0

One default path

Regular users edit in ChatCut. ChatGPT/Claude integration exists as a clearly separate power-user mode.

03 · P0

Outcome CTA

“Edit my first video” describes the task, not the destination. It also launches the demo instead of dumping users into an empty app.

04 · P1

Persistent session

Captions, motion, music and B-roll all modify one timeline, so every section feels like the same editing job.

05 · P1

Readable AI status

Users see exactly what changed: fillers removed, highlights found, B-roll placed and caption beats generated.

06 · P1

Follow-up is the product

The result is not a dead end. Users can say “faster”, “cleaner”, or “add B-roll” and see the existing edit update.

02 / Product System

ChatCut 不只需要一个 Agent，
还需要一个“剪辑系统”。

如果每一次生成都从零开始，AI 视频工具很难成为稳定的生产系统。真正重要的是：一次性交付、持续微调、规则复用与 Reference 复用能否同时成立。

两种工作流必须共存

Agentic Delivery

用户给原始素材、目标与约束，Agent 自己找素材、组织节奏、生成 B-roll / 音乐 / 字幕，直接交付多个版本。

Iterative Editing

用户已经有 80% 的成片，只想说：“这段快一点”“字幕全部大 20%”“把这一组 B-roll 换掉”。系统只改局部，不重新发明整个作品。

视频也需要 Design System

成熟 UI 产品不会因为“按钮大一点”就重新设计整个页面，而是通过 token 和 component 约束保持一致。视频也需要类似的结构。

Hook PatternCaption StylePacingB-roll RuleMusic ProfileCTA Pattern

我把它叫做 Cut System：一组项目级 / 品牌级的剪辑规则。它让“改一个规则，全局一致变化”成为可能。

Reference 不应该只是“给模型看个视频”

我更希望它接近 Mobbin 对产品设计的抽象：Mobbin 把设计参考拆成 Screen 和 Flow；视频可以拆成 Clip / Shot 与 Cut Flow。

Hook0–2s
Proof2–6s
Demo6–15s
Offer15–22s
CTA22–26s

每一段不仅有画面，还带着时长、轨道、字幕、转场、音乐、素材来源。这样 Reference 才能真正被“Apply”，而不是只做风格模仿。

最终结构

Brief → 自动找 Reference → 拆 Cut Flow → Agent First Cut → 用 Cut System 微调 → 生成变体。

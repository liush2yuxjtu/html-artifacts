# Original homepage design systems — 2026-09-15

Reverse-engineered reference snapshots of the **current ChatCut** and **current Cursor** homepages.

This folder intentionally contains **no redesign proposal**. The goal is to preserve the originals as a reusable design-system reference and static visual reproduction.

## Files

- [`design.md`](./design.md) — source-of-truth design specification for both sites
- [`chatcut/design-system.css`](./chatcut/design-system.css) — ChatCut tokens + component primitives
- [`chatcut/index.html`](./chatcut/index.html) — ChatCut static reproduction
- [`cursor/design-system.css`](./cursor/design-system.css) — Cursor tokens + component primitives
- [`cursor/index.html`](./cursor/index.html) — Cursor static reproduction
- [`index.html`](./index.html) — reference landing page

## Reference sources

- https://chatcut.io/
- https://cursor.com/

Capture date: **2026-09-15**.

Measurements were taken from the live rendered pages using browser inspection and are marked as observed or estimated in `design.md`. Product mock content is reconstructed in HTML/CSS so the repository does not depend on proprietary application code. Secondary prose is shortened where it does not affect visual geometry.
